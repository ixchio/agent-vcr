They edit repositories, call tools, mutate state, and fail halfway through.

A trace can explain the failure. Agent VCR gives you a boundary you can actually restore.

The hard part is the filesystem

Rollback means the files, too.

Agent VCR creates an isolated Git branch for the transaction and pairs every savepoint with a private local-file snapshot.

  • Tracked contentRestored from Git savepoint commits.
  • Ignored and untracked contentEligible pre-existing files are escrowed under .git/vcr-escrow, outside Git objects and VCR recordings.
  • Safe final commitChanges made after the last savepoint are finalized on the transaction branch before it is merged.
  • Fail-closed pathsAbsolute paths, .., and resolved-parent symlink escapes are rejected.
Read the transaction contract
workspace.py
from agent_vcr.integrations.openhands import ACIDWorkspace

tx = ACIDWorkspace("/repo")
tx.begin("task-42")

tx.savepoint(
    {"plan": "refactor auth"},
    node_name="planner",
)

# Agent edits code and local files.
tx.rollback(to_frame_index=0)

# Or accept all final work, including
# changes after the last savepoint.
tx.commit()

A tighter debugging loop

Recover the run. Prove the fix.

  1. 1
    Record

    Create a portable execution artifact while the agent runs.

  2. 2
    Rewind

    Return memory and workspace state to the selected boundary.

  3. 3
    Correct

    Patch the prompt, context, tool output, code, or policy.

  4. 4
    Replay

    Reuse verified work only when the full identity still matches.

  5. 5
    Gate

    Compare the candidate recording with reviewed expectations in CI.

Clear boundary

Local recovery, not magic.

Agent VCR can restore recorded state and repository-local files. It cannot undo email, payments, database writes, or arbitrary external APIs. Put consequential tools behind approvals and explicit compensation.
