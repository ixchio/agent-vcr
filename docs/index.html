The Problem

Debugging agents is a nightmare.

When an agent fails late in a repository-changing run, a trace alone cannot restore the files it modified or recover the local configuration it deleted.

Every logic error costs minutes of wall time and dollars in wasted LLM tokens. At scale, this kills iteration speed entirely.

  • Re-run entire chain for every small fix
  • State and filesystem recovery are separate problems
  • Pre-existing ignored files can be mutated in place
  • A fixed run still needs a repeatable regression gate
The Solution

Rewind. Fix. Resume.

Agent VCR records your agent's complete state at every step into a local JSONL file. When something breaks, you jump straight to the failing frame.

Edit the state — fix a bad prompt, inject corrected context, patch a tool output — then resume execution forward from that exact point.

  • Jump to any frame instantly
  • Full state snapshot at every step
  • Edit state and resume mid-chain
  • Fork runs to compare variants

from agent_vcr import VCRPlayer
from agent_vcr.models import ResumeConfig

player = VCRPlayer.load(".vcr/debug_run.vcr")

# Jump to the failing step
state = player.goto_frame(7)
print(state)          # Inspect full state

# Resume from step 7 with an explicit override
config = ResumeConfig(
    from_frame=7,
    state_overrides={"prompt": "Corrected prompt"},
)
player.resume(agent_callable, config)

Integrations

Use a native adapter or map your framework's lifecycle events to the recorder API.

langgraph_agent.py 
from typing import TypedDict

from langgraph.graph import StateGraph
from agent_vcr import VCRRecorder
from agent_vcr.integrations.langgraph import VCRLangGraph

class AgentState(TypedDict):
    query: str

builder = StateGraph(AgentState)
recorder = VCRRecorder()
recorder.start_session("langgraph-run")
instrumentation = VCRLangGraph(recorder)

builder.add_node("planner", instrumentation.wrap_node("planner", planner_node))
builder.add_node("coder", instrumentation.wrap_node("coder", coder_node))
builder.set_entry_point("planner")
builder.add_edge("planner", "coder")
builder.set_finish_point("coder")

graph = builder.compile()
result = graph.invoke({"query": "Build a todo app"})
recorder.save()

from agent_vcr import VCRRecorder

Where Agent VCR fits

Use observability for fleet visibility. Add Agent VCR when the run itself needs an undo, replay, or regression boundary.

Use it with observability

Keep your telemetry platform for traces, dashboards, and evaluation. Agent VCR focuses on local execution recovery and reproducible evidence.

Use it with framework checkpoints

LangGraph checkpointers persist graph state. Agent VCR adds portable JSONL, filesystem rollback, replay bundles, and framework-neutral CI datasets.

Know the boundary

Git cannot undo email, payment, or third-party API effects. Put consequential tools behind approval and explicit workflow compensation.

API Reference

Minimal, predictable interfaces.

VCRRecorder Core 
# Start a recording session
recorder.start_session(
    session_id: str = None,
    metadata: dict = None,
    tags: list[str] = None,
) -> Session

# Record one agent step
recorder.record_step(
    node_name: str,
    input_state: dict,
    output_state: dict,
    metadata: FrameMetadata = None,
) -> Frame

# Convenience recorders
recorder.record_llm_call(...)
recorder.record_tool_call(...)
recorder.record_error(...)

# Save & fork
recorder.save() -> Path
recorder.fork(from_frame: int) -> VCRRecorder
VCRPlayer Core 
# Load a saved session
player = VCRPlayer.load(filepath: str)

# Time-travel
player.goto_frame(index: int) -> dict
player.get_frame(index: int) -> Frame

# Inspect
player.list_nodes() -> list[str]
player.get_errors() -> list[Frame]
player.compare_frames(a: int, b: int) -> dict

# Resume execution
player.resume(
    agent_callable: Callable,
    config: ResumeConfig,
) -> str

# Export
player.export_state(frame_index: int) -> dict
ResumeConfig Config 
# Configure how replay works
ResumeConfig(
    from_frame: int,

    # Optional: override state before resume
    state_overrides: dict = {},

    # FORK: new session from this point
    # REPLAY: re-run same inputs
    # MOCK: use injected mock values
    mode: ResumeMode = FORK,

    # Skip specific nodes
    skip_nodes: list[str] = [],

    # Inject mocks for tool calls
    inject_mocks: dict = {},
)

ACID Transactions for Agents

Databases solved partial failure 40 years ago. Agents have the same problem.

Without ACID

Agent fails, filesystem is polluted.

Your agent hallucinated bad code on step 5. You roll back the state object, but the files are still on disk. Half-written modules, bad imports, broken configs — all still there.

  • State rolled back, but files remain
  • Parallel agents clobber each other's work
  • No atomic "undo" for the filesystem
With ACID

Rollback restores the selected boundary.

Git savepoints restore tracked content. Per-savepoint SHA-256 escrow restores eligible pre-existing untracked and ignored files such as .env without putting their bytes in Git or VCR recordings.

  • BEGIN creates an isolated branch
  • SAVEPOINT = state + filesystem checkpoint
  • ROLLBACK = tracked restore + local-file escrow
  • Hallucinated local files are removed
  • COMMIT = clean merge into main
acid_demo.py 
from agent_vcr import VCRRecorder
from agent_vcr.integrations.openhands import ACIDWorkspace

recorder = VCRRecorder()
acid = ACIDWorkspace("/my/workspace", recorder=recorder)

acid.begin(session_id="task-001")
acid.savepoint(state, node_name="coder")
acid.rollback(to_frame_index=0)  # state + files restored
acid.commit()                        # clean merge

👻 Ghost Replay — Reuse a Verified Execution

A full task-and-identity match returns recorded outputs without another model or tool call. Hybrid and branch modes rerun changed work explicitly.

ghost_replay.py 
from agent_vcr.golden_cache import GoldenRunCache

cache = GoldenRunCache()
identity = cache.build_identity(
    model="provider/model@revision",
    prompt_hash="sha256:prompt",
    code_commit="0123456789abcdef",
    tool_schema_hash="sha256:tools",
)

# After a successful run — save as a ghost
cache.save_golden_run("Build a REST API", recorder, identity=identity)

# Full identity hit — no provider execution
outputs, ledger = cache.replay("Build a REST API", identity=identity)
print(ledger)
# CostLedger(saved=100% | $0.0123 | 4,100 tokens | 2,349ms)

Deterministic Fingerprinting

Task and canonical identity JSON are SHA-256 fingerprinted. Nested key order is stable; prompt, model, code, tool, or dependency drift can invalidate reuse.

Cost Ledger

Tracks original tokens vs replay: dollars saved, milliseconds saved, percentage reduction. Shows exactly what Ghost Replay saved you.

Cache Invalidation

Call cache.invalidate(task) when the underlying logic changes and the ghost is no longer valid. Simple and explicit.

🛡️ OpenHands Sentinel

Local AST quality guard for AI agents. It can inspect OpenHands file-write events, record findings, and feed warnings back into the active session.

The Codebase Monster

Agents write bad code at scale.

AI agents duplicate functions across files, create 200-line monolithic handlers, and ignore existing abstractions. The codebase degrades with every task.

  • Duplicated functions across files
  • Monolithic functions with 10+ params
  • Cyclomatic complexity through the roof
  • No human around to catch it in real-time
Sentinel Catches It

Quality feedback inside the run.

Sentinel hooks into the OpenHands EventStream and runs local AST analysis after file writes. When violations are detected, it emits an auditable warning the runtime can return to the agent.

  • Cross-file duplicate function detection
  • Complexity & length spike alerts
  • Warnings can be fed back to the active agent
  • Full audit trail via agent-vcr

Local AST Engine

The analysis engine uses Python's built-in ast module. It needs no model key or cloud analysis service, so source stays in the local process.

Trajectory-Aware

Unlike standard linters, Sentinel tracks function definitions across the entire session. It detects duplicates that span multiple files.

Frame Size Guardrails

Detects and warns about oversized VCR frames (the OpenHands issue #7402 pattern) before they pollute the recording.

"Why not just use LangGraph's built-in time-travel?"

LangGraph's checkpointer persists graph state at every super-step. If you only need state inspection within LangGraph, it's a solid built-in. But state checkpoints aren't the whole picture.

LangGraph Checkpointer Agent VCR
Checkpoint in-memory state ✅ ✅
Rollback files on disk (Git + local escrow) ❌ ✅
Full identity-matched Ghost Replay ❌ ✅
Sentinel (real-time AST quality guard) ❌ ✅
Runtime scope LangGraph Framework-neutral recorder + adapters
Portable execution artifact Checkpointer backend contract JSONL + SHA-256 replay bundle

LangGraph's checkpointer and Agent VCR solve different layers. Use graph-native persistence for graph state; add ACIDWorkspace when tracked files and eligible pre-existing local files must return to the same boundary.
