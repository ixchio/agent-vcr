18-second demo

Roll back an agent's damage, then replay the good run.

One ACID workspace transaction protects agent state and the working tree, restores an overwritten secret, and the verified run is replayed with no model call.

  • Runtime18 s at 30 fps
  • SourceA real ACIDWorkspace run
  • IntegrityFile hashes restored
  • Replay cost$0.00

What you're watching

  1. Savepoint. An isolated git savepoint, plus a private copy of the ignored files git can't restore.
  2. Drift. The agent corrupts tracked code, adds a hallucinated file and overwrites a pre-existing .env.
  3. Rollback. Tracked code returns to the savepoint, the new file disappears and the secret comes back byte for byte.
  4. Replay. Ghost Replay serves the recorded frames with zero LLM calls, zero new tokens and zero model cost.

scripts/render_demo.py builds a disposable git repository, runs the real transaction and replay APIs, checks the before-and-after hashes, and only then renders the result. The placeholder secret never enters git objects or the recording.
