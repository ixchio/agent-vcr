01 / Savepoint

Start from a known-good state.

Agent VCR creates an isolated Git savepoint and privately escrows the ignored files Git cannot restore.

02 / Drift

See destructive work as it happens.

The agent corrupts tracked code, adds a hallucinated file, and overwrites a pre-existing .env.

03 / Rollback

Restore state and files together.

Tracked code returns to the savepoint, new files disappear, and the ignored secret is restored byte-for-byte.

04 / Replay

Reuse the verified run.

Ghost Replay serves the recorded frames locally with zero LLM calls, zero new tokens, and zero model cost.

Generated from evidence, not staged output.

scripts/render_demo.py creates a disposable Git repository, runs the actual transaction and replay APIs, verifies the before-and-after hashes, and only then renders the measured result. The placeholder secret used for this demo never enters Git objects or the VCR recording.
